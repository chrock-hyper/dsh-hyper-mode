双击 `index.html` 即玩：纯静态、零依赖、无网络请求、断网可用。

## 玩法

1. 点「开始游戏」进入对局；
2. 掷骰：掷到 6 才能让基地里的棋子起飞，且掷 6 可以连掷；
3. 点发光的棋子走格；落点若有敌方棋子，把它撞回基地（归航段与终点是安全区）；
4. 四枚棋子全部抵达中心终点即胜。

## 实现要点

- **单文件、经典 `<script>`**：`file://` 下 `type="module"` 与相对 import 会被 CORS 拦掉，双击会白屏；
- **棋子只存进度 `p`，不存坐标**：位置是 `p` 的纯函数，状态与坐标不可能对不上；
- **撞子按主环绝对格号判定**：不同阵营的相同 `p` 落在不同格，按 `p` 相等判会撞错子；
- **动画消费事件流**：规则层不碰动画，动画层不做规则判断；
- **棋盘静态层离屏缓存**：每帧只 `drawImage` + 画动态元素，`ResizeObserver` 时才重建。
